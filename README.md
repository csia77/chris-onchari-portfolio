# Chris Onchari Ondieki — Portfolio

Personal portfolio website showcasing full-stack JavaScript and Web3 development work.

**Live:** Deploy to GitHub Pages or Vercel (see below).

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Structure | Semantic HTML5 |
| Styling | Vanilla CSS (Custom Properties) |
| Logic | Vanilla JavaScript (ES6+) |
| Fonts | Inter + JetBrains Mono (Google Fonts) |
| Hosting | GitHub Pages or Vercel |

> No frameworks. No build tools. No npm dependencies.

---

## Quick Start

```bash
# Clone
git clone https://github.com/csia77/polish-portfolio-website.git
cd polish-portfolio-website

# Open directly
# Just open index.html in your browser

# Or use a local server
npx serve . -p 3000
# Visit http://localhost:3000
```

---

## Deploy to GitHub Pages

1. Push the repository to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save**
5. Your site will be live at `https://csia77.github.io/polish-portfolio-website/`
